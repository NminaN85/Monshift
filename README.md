# MonShift

MonShift est une application web progressive
pour suivre les heures de travail.

## Fonctionnalités

- Entrée
- Sortie
- Plusieurs pauses
- Ajout de jours passés
- Modification des journées
- Calendrier
- Statistiques
- Heures supplémentaires
- Export CSV
- Backup JSON
- Restore
- Français
- English
- العربية
- Dark Mode
- Fonctionnement offline

## Structure

- index.html
- css/style.css
- js/app.js
- js/ui.js
- js/storage.js
- js/calculations.js
- js/calendar.js
- js/stats.js
- js/translations.js
- manifest.webmanifest
- sw.js
- assets/icon.svg

Projet statique.
